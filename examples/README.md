# KRDS React UIKit Examples

This directory contains examples of how to use the KRDS React UIKit in your projects.

## Examples

### 1. Basic Usage (`basic-usage`)
A simple demonstration of Accordion and Button components.

#### How to run:

1.  **Install dependencies at the root level** (if you haven't already):
    ```bash
    npm install
    ```

2.  **Navigate to the example directory**:
    ```bash
    cd examples/basic-usage
    ```

3.  **Run the development server**:
    ```bash
    npx vite
    ```

4.  **Open your browser**:
    Navigate to `http://localhost:3000` to see the components in action.

## Implementation Notes

The examples link directly to the source code of the UIKit in `../../src/UIKit`. This allows you to see changes in the UIKit reflected immediately in the example page during development.
