# KRDS Resources & Developer Kit

Essential tools and links for implementing the KRDS (Korean Government Design System) in your project.

## 📦 COMPONENT KITS (HTML/CSS/JS)
The official **HTML Component Kit** provides standardized markup and assets.

### Installation (NPM)
```bash
npm i krds-uiux
```
*Note: Includes compiled CSS, JS, fonts, and SVG icons. Copy the `/resources` folder to your project root to manage asset paths efficiently.*

### CDN Quick Start (JSDelivr)
- **CSS**: `https://cdn.jsdelivr.net/npm/krds-uiux@latest/resources/cdn/krds.min.css`
- **JS**: `https://cdn.jsdelivr.net/npm/krds-uiux@latest/resources/cdn/krds.min.js`

## 🎨 DESIGN ASSETS
- **Figma Design Tokens**: Available in `tokens/figma_token.json` within the NPM package or GitHub.
- **Icon Library**: Standardized SVG icons optimized for government services.
- **Style Customization**: Use design tokens to generate tailored CSS variables for "Adaptive" style compliance.
