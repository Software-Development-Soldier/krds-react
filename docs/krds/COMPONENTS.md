# KRDS Standard Component Inventory

KRDS provides **46 standard components** designed for semantic compliance and consistent UI/UX. All components follow the `krds-` class naming convention.

## 🏛️ IDENTITY (Mandatory)
- **Official Banner (Masthead)**: `.krds-masthead` - Identifies the site as an official government service.
- **Agency Identifier**: `.krds-identifier` - Display of agency logo and name.
- **Header**: `.krds-header` - Global navigation and search toggle.
- **Footer**: `.krds-footer` - Legal links, contact info, and site map.

## 🧭 NAVIGATION
- **Skip Link**: `.krds-skip-link` - Accessibility requirement for keyboard users.
- **Breadcrumb**: `.krds-breadcrumb` - Hierarchical path indicators.
- **Pagination**: `.krds-pagination` - Controls for multi-page lists.
- **Side Navigation**: `.krds-side-nav` - Deep content navigation for specific sections.
- **Tabs**: `.krds-tabs` - For switching contextual views.

## 📝 INPUT & SELECTION
- **Input Fields**: `.krds-input` - Text, email, and password fields.
- **Select Menu**: `.krds-form-select` - Standardized dropdowns.
- **Checkbox**: `.krds-checkbox` - Multi-selection support.
- **Radio Buttons**: `.krds-radio` - Single selection support.
- **Text Area**: `.krds-textarea` - For long-form text entry.
- **File Upload**: `.krds-file-upload` - Interaction for attachments.

## 🔘 ACTIONS & FEEDBACK
- **Buttons**: `.krds-btn` - Primary, secondary, tertiary, and icon-only variants.
- **Alerts**: `.krds-alert` - Info, Success, Warning, and Error banners.
- **Modals**: `.krds-modal` - Dialogs for focused user interaction.
- **Tags/Badges**: `.krds-badge` - Status indicators and metadata labels.
- **Progress Bars**: `.krds-progress` - Visual status for long-running processes.

## 🧩 BASE & SERVICE PATTERNS
*These are combinations of components used for specific tasks.*

### Global Patterns
- **Login Flow**: Standard login/authentication page patterns.
- **Search Result**: Integrated search input and result listing.
- **Form Patterns**: Personal information entry and multi-step forms.

### Service UX Blueprints
- **Petition/Application (신청)**: Step-by-step UX flows for public services.
- **Inquiry/Search (조회)**: Deep search and data retrieval patterns.
